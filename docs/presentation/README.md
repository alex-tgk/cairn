Render the deck from the repository root with:

```sh
npx @marp-team/marp-cli docs/presentation/cairn-cop-talk-slides.md \
  --theme-set docs/presentation/cairn-talk-theme.css \
  --html -o docs/presentation/cairn-cop-talk-slides.html
```
